## A Note about AI

College algebra is the bridge from arithmetic to abstract reasoning with symbols. The model is fluent in symbolic manipulation and unreliable as a calculator. The note examines where each property serves the student.

The textbook teaches you to manipulate expressions, solve equations and inequalities, work with functions, and reason about systems. Every operation has a procedure. The procedures are the curriculum. The model has read every college algebra textbook in print and will explain any procedure in plain language. The fluency is genuinely useful for the *explanation* of why a procedure works; it is unreliable for the *execution* of a specific problem.

Where the model genuinely helps: explaining a concept multiple ways (what factoring is, what a function is, what a solution means), walking through a worked example with attention to which step is the conceptual move and which step is the arithmetic move, producing structured practice problems at varied difficulty, identifying common errors before you make them, and translating between graphical and algebraic representations of the same object.

Where the model does damage: doing the algebra. The model will distribute incorrectly, drop a sign, misapply the quadratic formula, simplify a rational expression wrong, and present the result with the confidence it would use for correct work. The errors cluster around the steps where students typically make errors, which means the model is not a useful proofreader for your work — its own errors and yours come from the same statistical distribution.

A specific failure mode worth naming: the model produces final answers that are right in form (a number where a number was expected) and wrong in value. A student checking against the model gets a false confirmation. The model also tends to "simplify" expressions that should not be simplified for the problem at hand, producing a transformed problem that is no longer the problem the textbook asked.

The rule that covers all three: explanation from the model; the algebra from your pen. Algebra is taught through repetition of procedure. If the model performs the procedure for you, you have not learned it, and the next chapter will surface the gap. Use the model to understand why a method works; use your own work to apply it.
